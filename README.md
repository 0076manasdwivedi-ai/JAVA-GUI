# Java Swing Student Registration System

A Desktop GUI application built using **Java Swing** and **AWT** to register students with field validation and interactive form elements.

## Features
* **Form Components:** Heading, Name, Age, Roll Number, Branch, Gender Radio Buttons, Terms Checkbox, and Action Buttons.
* **Input Validation:** Prevents submission if fields are empty or required options are unselected.
* **Reset Feature:** Clears all fields and radio button choices seamlessly.
* **Pop-up Confirmation:** Displays formatted registration details upon valid submission.

## Requirements
* Java Development Kit (JDK 8 or higher)
